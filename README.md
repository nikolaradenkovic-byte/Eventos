Full-stack aplikacija za upravljanje dogadjajima.

## Tehnologije

### Backend
* **Framework:** `ASP.NET`
* **ORM:** `Dapper`
* **Baza podataka:** `SQL Express/Azure SQL Database`
* **Dokumentacija:** `Swagger (OpenAPI)`

### Mobile
* **Framework:** `React Native Expo`
* **HTTP Klijent:** `Axios`

### Frontend
* **Framework:** `React (Vite)`
* **CSS Framework:** `Tailwind`
* **HTTP Klijent:** `Axios`
